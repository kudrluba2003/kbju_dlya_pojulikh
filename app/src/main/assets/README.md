# Папка assets

Сюда положите файл **`products_seed.json`** — большую базу продуктов, собранную
скриптом `tools/scrape_pbprog.py` (см. описание в корневом README.md).

Формат файла:

```json
[
  {"name": "Овсяная каша", "calories": 88.0, "protein": 3.0, "fat": 1.7, "carbs": 15.0, "category": "Каши"}
]
```

Как это работает:

- При **первом** запуске приложения `DatabaseSeeder` прочитает этот файл и запишет
  все продукты в таблицу `food` базы Room (порциями по 500, в одной транзакции).
- Если таблица уже заполнена — сеанс не повторяется: база остаётся локальной и
  мгновенной, интернет не нужен.
- Если файла здесь нет — сеется встроенный список из 78 продуктов (`SeedData`),
  так что приложение работает и без JSON.

Важно: на устройстве, где база уже засеяна, новый файл подхватится только после
переустановки приложения (или после увеличения `version` в `AppDatabase` —
миграция деструктивная, данные дневника будут потеряны).
